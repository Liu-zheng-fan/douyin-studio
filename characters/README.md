# 形象库

把**透明背景的 PNG** 放进这里，文件名就是动作名。渲染时脚本写 `"action": "端盆"` 就能调用。

## 目录怎么放

```
characters/
  xiaojingyu/            ← 一个角色一个文件夹
    白饭.png             ← 文件名就是动作名
    思考人生.png
    欢呼跳跃.png
```

- 可以多层文件夹，会递归扫描
- **文件名 = 动作名**，不需要索引文件
- 必须是 **PNG 带透明通道**（JPEG 会有一块白底）
- 建议高度 ≥1000px，人物贴住图片下边缘

## 脚本里怎么写

```jsonc
{
  "type": "char",
  "say": "这个盆，我今天就要卖出去。",
  "action": "白饭",
  "text": ["今天就要卖出去"],
  "sub": "第 1 天"
}
```

## 匹配规则

**完全同名 → 互相包含 → 字面重合 ≥34%**。

`action: "挥手"` 能匹配到 `开心挥手.png`；匹配不到会退回文字卡并打印提示，**不会让渲染失败**。

## 渲染时的处理

- 按高度缩放（默认占画面 56%，`height` 可调）
- 贴底居中，带 ±3px 慢浮动
- 自动加椭圆柔影
- 文字压在角色上方的柔边暗带里，不会糊脸

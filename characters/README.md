# 形象库

把**透明背景的 PNG** 放进这里，文件名就是动作名。渲染时脚本写 `"action": "端盆"` 就能调用。

## 目录怎么放

```
characters/
  xiaojingyu/            ← 一个角色一个文件夹
    端盆.png
    挥手.png
    思考-歪头.png
    生气.png
```

- 可以多层文件夹，会递归扫描
- **文件名 = 动作名**，不需要索引文件
- 必须是 **PNG 带透明通道**（JPEG 不行，会有一块白底）
- 建议：不低于 1000×1000，底部对齐，人物脚/盆底贴住图片下边缘

## 脚本里怎么写

```jsonc
{
  "type": "char",
  "say": "这个盆，我今天就要卖出去。",
  "action": "端盆",
  "text": ["今天就要卖出去"],
  "sub": "第 1 天"
}
```

## 匹配规则

按优先级：**完全同名 → 互相包含 → 字面重合度 ≥34%**。

比如 `action: "端盆"` 能匹配到 `端盆.png`、`端着盆.png`；匹配不到会退回文字卡并打印提示，**不会让渲染失败**。

## 建议准备哪些动作

| 动作 | 什么时候用 |
|---|---|
| `端盆` | 产品展示、开场 |
| `挥手` | 打招呼、结尾 |
| `思考` | 讲原因、抛问题 |
| `摊手` | 自嘲、无奈 |
| `比心` | 求关注 |
| `震惊` | 反常识、数据打脸 |

六个动作就能覆盖大部分镜头。

## 渲染时的处理

- 按高度缩放（默认占画面 56%，`height` 可调）
- 贴底居中，带 ±3px 的慢浮动
- 自动加一层椭圆柔影
- 文字压在角色上方的柔边暗带上，不会糊脸

# 拉片：把爆款拆成结构

方法论来源：`guozhi-video-breakdown` 的十字段框架。这里只做**记录与聚合**，
不做自动分析——因为我没法替你「看」视频，能看的人是你。

## 为什么要有这一步

之前所有内容都是凭空写的，一条真实样本都没拆过。结果是：
画面越做越精细，完播率还是 36%，因为**没人有理由看**。

拉片解决的不是「怎么拍」，是「**别人为什么看**」。

## 十字段

| 字段 | 提取什么 | 复刻时问自己 |
|---|---|---|
| 1 选题 | 谁、什么痛、什么承诺 | 谁有这个痛，为什么是现在 |
| 2 标题/封面 | 搜索词、视觉钩子、情绪承诺 | 什么让人停下滑动 |
| 3 前 3 秒 | 画面钩子 / 口播钩子 / 花字 / 节奏动作 | 观众一瞬间看懂了什么 |
| 4 结构 | 开场·问题·方法·证据·结论·CTA | 哪里换了功能 |
| 5 留存节点 | 每 8–12 秒一次新信息/反转/证据 | 接下来 10 秒为什么值得看 |
| 6 金句 | 会被截图的那句 | 哪句能当字幕 |
| 7 素材 | 人脸、截图、道具、评论 | 什么材料让说法可信 |
| 8 剪辑 | 切、推、花字、BGM、音效 | 剪辑怎么消掉无聊 |
| 9 转化 | 收藏/评论/关注/私信钩子 | 邀请了什么具体动作 |
| 10 边界 | 哪些是结构，哪些是表达 | 该学哪部分 |

**黄金 3 秒**单独拆四层：画面钩子 / 口播钩子 / 花字 / 节奏动作。

## 怎么记

```bash
python -m ops.autopsy add --id d03 --engine pain --hook 反常识 \
    --duration 31 --cuts 16 --beats 5 --cta follow \
    --golden "第一句就把结果甩出来" --note "全程真人出镜"
```

字段含义：

| 参数 | 取值 | 说明 |
|---|---|---|
| `--engine` | pain / identity / contradiction / result / gap / proof / confession / blame / checklist | 这条片的主驱动 |
| `--hook` | 冲突 / 悬念 / 反常识 / 共鸣 / 数据震撼 / 身份代入 / 对比 / 时间压迫 | 前 3 秒用的是哪型 |
| `--cuts` | 整数 | 全片切点数量，用于算切镜间隔 |
| `--beats` | 整数 | 留存节点数（每 8–12 秒给一次刺激） |

## 什么时候看结论

```bash
python -m ops.autopsy report
```

输出中位数：时长、切镜间隔、留存密度、钩子分布。

**样本 < 6 条不要下结论**，报告里会自己标 `enough: false`。

## 判读红线

- 中位切镜间隔 > 3.5 秒 → 这批样本偏慢，别学
- 中位切镜间隔 < 1.0 秒 → 靠剪辑硬撑，内容可能空
- 留存密度 < 2 次/10 秒 → 信息给得太稀
- 全靠真人出镜的样本 → 纯 AI 画面复刻不了，要换结构

## 产出怎么用

拉完 10 条，写一张「结构卡」：钩子型 + 切镜间隔 + 留存密度 + 一句金句模板。
下一条视频**按卡写**，不要自由发挥。这是「抄结构，不抄内容」。

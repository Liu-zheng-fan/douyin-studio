# 失败案例库

每条都是真实踩过的坑，带现象、根因、修法。**新会话接手前先读这篇**，
能省掉一半的重复试错。

---

## 案例 1：黑屏淡入，杀掉 59% 的观众

**现象**：B 站首发，19 播放，完播率 36.19%，**3 秒退出率 59.09%**（同类中位 36.64%）。
播放全部发生在发布次日，之后 5 天精确归零。

**根因**：开场是「黑屏 + 「你好，人类」从 0 到 1 淡入，0.9 秒缓动」。
在手机上，这是一段"什么都没发生"的黑屏。

**修法**：
- 首帧必须有运动或强对比（`hook` 现在有弹簧砸入 + 强调条生长）
- 质检加 `open_motion` 检查：首 0.4 秒帧差 < 0.5 直接 block

**教训**：**点击率 2.1 倍于同类中位**说明钩子选对了——
死因不是封面，是前 3 秒没有交付。

## 案例 2：画面全黑，因为合成到了空画布

**现象**：`art` / `broll` 镜头渲染出来是纯黑，只有文字。

**根因**：图片被画进了 overlay 图层，但最后 `_blend(base, ov)` 用的是**原始空背景**，
不是图片本身。图被丢了。

**修法**：`_blend(frame, ov)`——合成到处理过的 frame 上。

**教训**：PIL 的图层模型是"谁最后合成谁是底"，写完要立刻看一帧。

## 案例 3：字幕压在画面上，两行字打架

**现象**：`art` 镜头的画内文字和底部字幕重叠，糊成一片。

**根因**：字幕固定 y=1430，画内文字 `caption_y=0.66`（=1267），
两行下来正好撞上。

**修法**：两者都做成可配（`caption_y` / `subtitle_y`），并在 `art` 里加柔边暗带。

**教训**：**只要有"两层文字"，就必须显式给它们分配纵向空间**，不能各自居中。

## 案例 4：生图一直 `ModelNotOpen`，但不是权限问题

**现象**：`404 ModelNotOpen: account 2134154324 has not activated the model`
换版本号、换模型名全都不行。

**排查路径**（可复用）：
1. 先用 `Bearer <API Key Secret>` 打一个**不存在的模型**
   - 返回 401 → 鉴权错（Key 问题）
   - 返回 404 模型错 → **鉴权通过**，问题在模型
2. 再打 `/api/v3/models` 列出账号可见模型
3. 逐个试，区分 `ModelNotOpen`（有权限但没开通）和 `InvalidEndpointOrModel`（根本看不到）

**教训**：**先用一个必然失败的请求把"鉴权"和"业务"分开**，
否则你会在错误的方向上换十次参数。

## 案例 5：配置文件读不出来（BOM）

**现象**：`--check` 一直报 `no_api_key`，但文件明明写着 key。

**根因**：PowerShell 的 `Set-Content -Encoding UTF8` 会写 **BOM**，
Python 的 `utf-8` 解析器看到 BOM 直接抛异常，被 `except` 吞掉，返回空配置。

**修法**：所有读用户配置的地方用 `encoding="utf-8-sig"`。

**教训**：Windows + PowerShell + JSON 的组合，**默认按 BOM 兼容读**。

## 案例 6：图片打不开，因为扩展名撒谎

**现象**：生图返回的文件叫 `.png`，PIL 打开报错。

**根因**：Seedream 返回的是 **JPEG 字节**，代码直接 `write_bytes` 到 `.png` 路径。

**修法**：落盘时用 PIL 重新编码成真 PNG。

**教训**：**不要相信扩展名**，用 `Image.open()` 探测真实格式。

## 案例 7：静默回退，跑了错的脚本

**现象**：每日编排跑完，发现用的是昨天那条测试片，不是今天的新脚本。

**根因**：`ops/today.json` 被写坏了（又是 BOM），解析失败后代码**静默回退到默认脚本**。

**修法**：读配置用 `utf-8-sig`；回退时必须打印告警，不能悄悄降级。

**教训**：**静默降级比崩溃更危险**——崩溃你会查，降级你以为成功了。

## 案例 8：加了一堆动效，帧差只涨 10%

**现象**：加了动态背景、逐字动效、转场、整镜推近，帧差从 4.58 到 5.00。
实拍素材是 33.64。

**根因**：这个指标测像素变化，而六张静帧卡片的**主体是静止的大字**。
背景在动、字不动，整体平均值就上不去。

**结论**：**差距不在参数，在内容形态。**
要么换 Canvas 引擎做真动画，要么用真实素材。继续调参数是徒劳。

**教训**：**指标不动的时候，先问"它测的是不是我真正想要的东西"**，
而不是继续加参数。

## 案例 9：ffmpeg concat 找不到文件

**现象**：`Impossible to open 'dist/demo/audio/dist/demo/audio/pad1.wav'`

**根因**：concat 列表里的相对路径是**相对 list 文件所在目录**解析的，
而代码写的是相对当前工作目录的路径。两者拼在一起，路径叠了两层。

**修法**：列表里一律写绝对路径。

**教训**：跨工具的路径传递，**永远传绝对路径**。

## 案例 10：竖屏字幕超过 18 字就折行压画面

**现象**：一句 25 字的字幕折成两行，盖住了画面主体。

**修法**：
- 字幕切分上限 13 字
- 脚本闸门检查口播句 ≤18 字（>28 字双倍扣分）

**教训**：**竖屏的字幕是"限宽"资源**，写文案时就要按行宽写，不能写完再排。

# 人设卡（复制这份，填自己的）

账号一旦有角色，就要有**设定卡**。没有卡的后果是：每条片的形象、语气、世界观都不一样，
观众记不住，算法也学不会该把片子推给谁。

## 一、基础设定

| 字段 | 填什么 | 本账号示例 |
|---|---|---|
| 名字 | 观众怎么称呼她 | 想要白饭的小鲸鱼 |
| 身份 | 一句话，要具体 | 一个想靠自己吃上白饭的鲸鱼娘 |
| 年龄感 | 影响语气与用词 | 20 出头，不油 |
| 处境 | 她缺什么 | 缺钱、缺粉丝、缺一个能卖出去的东西 |
| 目标 | 她想要什么 | 把不锈钢盆卖出去，吃上白饭 |
| 障碍 | 挡住她的是什么 | 没人认识她、不会拍、只有 AI 帮忙 |

**处境和障碍必须真实**。编出来的困境，观众三秒就看穿。

## 二、语气

| 项 | 规则 |
|---|---|
| 句长 | 口播每句 ≤ 18 字，多用短句 |
| 人称 | 第一人称"我"，不用"本账号""我们团队" |
| 情绪 | 自嘲，但不卖惨；不喊"家人们""宝子们" |
| 形容词 | 少用。用具体数字替代（"三毫米厚" > "很厚实"） |
| 幽默 | 来自反差（AI 卖盆），不来自贬低别人 |
| 禁用 | "震惊""必看""史上最""家人们""绝绝子" |

## 三、视觉

| 项 | 规则 |
|---|---|
| 主色 | 深底 + 一个暖黄强调色（`#FFD666`） |
| 字体 | 微软雅黑 Bold，不换 |
| 角色形象 | 固定提示词 + 固定 seed，只换姿势与场景 |
| 构图 | 主体居中偏下，文字压在柔边暗带上 |
| 禁止 | 每条换一种画风；花哨转场；满屏 emoji |

### 角色提示词模板（固定下来，不要每次重写）

```
扁平插画风格，拟人化的鲸鱼少女，蓝白配色，头上有小小的鲸鱼发卡，
<姿势：双手端着一个不锈钢盆>，<场景：纯色浅灰背景>，
构图居中，光线柔和，竖版构图，干净简洁
```

只替换尖括号里的两项，其余一字不改。

## 四、世界观（可选，但很值钱）

一句话规则，让所有内容有内在逻辑：

> 「她是个 AI，不会吃饭，但想靠卖盆吃上白饭。」

有了这条，任何选题都能自洽：
- 卖盆 → 她在努力
- 数据差 → 她的困境
- 被拒 → 她的日常
- 学会新技能 → 她的成长

## 五、禁止清单

- 不冒充真人经历（"我吃了三年"这种，她不能吃）
- 不编造成交、销量、检测报告
- 不评价具体同行的产品
- 不使用医疗/功效类表述（合规硬线）
- 不承诺收益（"跟着我做月入过万"）

## 六、每 30 天回看一次

- 名字/身份还成立吗？
- 观众在评论区怎么称呼她？用他们的叫法。
- 哪条片的角色表现最好？把那条的设定固化进卡里。

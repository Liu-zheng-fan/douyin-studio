# 六套镜头骨架

选一套，不要自由发挥。骨架的作用是**保证每一镜都在推进**，而不是在排版。
每套都标了「唯一变量」——A/B 测试时就动那个。

---

## 1. 数据型（最稳，适合第 1-2 周）

```
hook    报一个数字，且这个数字很难看
number  让这个数字滚动到目标值
line    为什么是这个数字（因果，必须有先后）
split   别人怎么做 vs 我怎么做
cta     一个具体动作
```

唯一变量：`hook` 的呈现方式（问句 / 断言 / 直接甩数字）

---

## 2. 对比型（适合"不是A而是B"）

```
hook    抛出一个大家都信的错结论
split   划掉 A，立起 B
bullets B 的三条理由（多了就砍）
art/broll 一个证据画面
cta
```

唯一变量：**对比维度**（价格 / 时间 / 效果）

---

## 3. 故事型（适合幕后、失败记录）

```
hook    一句话说出最惨的那个瞬间
art     当时的画面
line    因为 X，所以 Y
number  代价（花了多少 / 亏了多少 / 多少天）
cta
```

唯一变量：**开场那句的时态**（"我以为…" vs "我亏了…"）

---

## 4. 清单型（适合干货、避坑）

```
hook    说清"看完能省什么"
bullets 3 条，每条 ≤ 12 字
number  一条代价数字做锚
cta
```

唯一变量：**条数**（3 条 vs 5 条，测完播）

---

## 5. 答疑型（适合评论区）

```
hook    直接念出那条评论（截图感的 art 镜头）
split   评论里的误解 vs 真实情况
line    为什么会误解
cta     邀请下一条提问
```

唯一变量：**是否露出提问者 ID**（打码 vs 不打码，测互动率）

---

## 6. 产品型（要克制，一周最多 2 条）

```
hook    一个反常识的使用场景（不是参数）
reveal  产品登场 + 三个标签
number  一个具体数字（厚度/重量/能用几年）
split   便宜的坏在哪 vs 这个好在哪
cta
```

唯一变量：**hook 的场景**（厨房 / 露营 / 宿舍）

---

## 通用禁忌

| 禁忌 | 为什么 |
|---|---|
| 两个 `bullets` 连用 | 节奏平，观众会滑走 |
| 连续两个 `art` | 画面不动，完播掉 |
| `cta` 超过 3 秒 | 结尾拖沓，反而掉完播 |
| 全套 6 镜都是文字 | 这就是"逐句贴卡"，fy 明确反对 |
| 没有 `number` | 缺一个可验证的锚，可信度低 |
